# Projeto de Análise de Dados com Python e SQL

## Sobre o projeto

Este projeto foi desenvolvido para praticar análise e manipulação de dados utilizando **Python e SQL**.

O objetivo é aplicar conceitos de programação, banco de dados e análise de dados em um projeto prático.

## Tecnologias utilizadas

* Python
* SQL
* Jupyter Notebook
* Banco de dados

## O que foi desenvolvido

* Manipulação de dados
* Consultas SQL
* Análise de informações
* Tratamento e organização dos dados
* Exercícios práticos de programação e banco de dados

## Arquivo principal

`projeto_analise_dados.ipynb`

O notebook contém o desenvolvimento do projeto, incluindo os códigos e análises realizadas.

## Objetivo

Este projeto faz parte da minha formação em **Engenharia de Software** e do meu processo de desenvolvimento de habilidades em **Python, SQL e análise de dados**.
